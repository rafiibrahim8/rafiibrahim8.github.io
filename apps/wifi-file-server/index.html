How it works

Four steps, no signup.

No accounts to make, no apps to install on the receiving device.

1

Pick a folder

Choose any folder on your device. Only that folder is exposed.

2

Tap Start

A QR code and local URL appear on the home screen.

3

Scan or open

Any phone, tablet, or laptop on the same Wi-Fi opens the URL.

4

Browse & download

It looks like a normal file listing in your browser. Stop the server when you're done.

Features

Built for the LAN, not the cloud.

Everything you need to move files between devices on your network — and nothing you don't.

Any browser, any device

No app install on the receiving side. Works on phones, laptops, tablets, smart TVs — anything that opens a URL.

QR code on the home screen

Connect another device by pointing its camera at the phone. No typing IPs.

Resumable downloads

HTTP range requests are supported, so paused or interrupted downloads pick up where they left off.

Folder upload

Pick a whole folder tree from a computer; the structure is preserved on the phone.

Multi-select

Pick several files at once, then bulk-download as a ZIP or bulk-delete.

Optional password

Basic auth available when you want a quick gate between you and the rest of the network.

Auto-stop on idle

Set the server to shut itself off after a configurable idle window. Forget to stop it; the app remembers for you.

Drop-box mode

Hide the file listing entirely and accept only uploads — useful when others need to drop files to you.

Home-screen widget

Start or stop the server with a single tap, without opening the app.

Privacy

Your files don't go anywhere.

No cloud. No account. No telemetry.

The server runs on your phone and serves files over your local Wi-Fi. Files never traverse the public internet. The app has no analytics SDKs, no third-party services, and doesn't phone home.

Read the full privacy policy →

  • All data stays on your device or your local network.
  • Optional credentials are stored locally only.
  • Transfer history persists across app restarts — on-device only.
  • No third-party SDKs, ads, or analytics.
  • Source is on GitHub — read it yourself.
